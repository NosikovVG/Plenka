🔎 Фильтры

На вкладке Склад можно фильтровать позиции сразу по типу плёнки → марке авто → модели → расположению. В каждом списке показано количество активных позиций. На телефоне панель фильтров скрыта под кнопкой 🔍 Фильтры — бейдж рядом показывает, сколько фильтров включено.

💡 Данные и хранение

Всё хранится локально в браузере — база в IndexedDB, вложения отдельным хранилищем. Интернет нужен только для подгрузки библиотек sql.js и pdf-lib.

Экспорт базы — через ⚙️ в шапке (файл .db, без вложений). Для полного переноса используйте кнопку 💾 — она создаёт резервную копию внутри браузера.
