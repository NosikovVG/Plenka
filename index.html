Отчёт

Умный поиск (ИИ)

Эта функция ищет лекала по смыслу, а не по точному вхождению. Например, по запросу «камри 18 фары» найдёт TOYOTA CAMRY 2018, а по «прадик 150» — Land Cruiser Prado 150.
Важно: для работы ИИ нужно один раз скачать модель (~25 МБ). Она сохранится в браузере и будет работать оффлайн. Данные никуда не отправляются — всё считается локально.
